# Subtitle Layout, Font Engine & In-Place Styling Reference

This document captures the exact CapCut macOS subtitle schema, bitmasks, font sandbox rules, and in-place timing preservation verified across projects `1026`, `1029`, `1014`, and `1030`.

---

## 1. Zero-Drift Rule: Always Style Existing CapCut Auto-Captions In-Place

- When a CapCut draft already has a `text` track containing `type = "subtitle"` segments (`Track 3` in standard CapCut projects), **never replace those segments with newly synthesized timestamps from an external `.mp4` Whisper pass**.
- **Why**: Compound clips (`subdrafts`) often have multiple audio tracks (`4+` audio layers) trimmed or shifted independently from the video segments (`v_spans`). Computing subtitle timestamps from video segment spans causes a `1–3s` cumulative drift in the second half of the film.
- **How to style in-place**:
  1. Keep `segment.target_timerange` and `segment.source_timerange` 100% untouched on every spoken subtitle segment.
  2. Mutate the linked `materials.texts[]` entry in-place (`font_path`, `font_name`, `font_size`, `text_color`, `check_flag`, `border_*`, `shadow_*`, `background_*`, `content`, `base_content`).
  3. Update `segment.clip.transform.y` (`-0.74` or `-0.78`) and synchronize `segment.clip.scale = {"x": 1.0, "y": 1.0}` with `segment.uniform_scale = {"on": true, "value": 1.0}`.
  4. Fix ASR typos against the script (`Mr Veal` -> `Mr. Vale`, `Coraline` -> `Corinne`, `8.47pm` -> `8:47 PM`) and balance long lines (`> 42–44` chars) into 2 lines with `\n`.
  5. Only remove pure non-speech noise hallucinations (`"All right."` / `"No."` generated by ASR on wind/door slams during silent scripted scenes), and simultaneously delete their `recognize_task_id` / `text_material_id` from `attachment_action_scene.json` (`caption_id_info`).

## 2. Mandatory CapCut Subtitle Schema Invariants

### 2.1 `content == base_content`
- In CapCut macOS (`v25.2+`), `type = "subtitle"` materials store both `content` (rich JSON string) and `base_content` (plain text string).
- If you modify line breaks (`\n`) or fix a word in `content["text"]` without updating `base_content` to the exact same string, CapCut's subtitle layout engine falls back to `base_content` or mis-renders the bounding box.
- **Always set**:
  ```python
  mat["base_content"] = text
  mat["content"] = json.dumps(content_obj, ensure_ascii=False)
  ```

### 2.2 `check_flag` Bitmask (`15` vs `23`)
CapCut uses `check_flag` (both on the `materials.texts[]` object and inside `content.styles[0].checkFlag` if present) as a bitmask controlling which visual layers render:
- `1`: Fill (`fill`)
- `2`: Stroke (`strokes` / `border_*`)
- `4`: Glow (`glow`)
- `8`: Drop Shadow (`shadows` / `shadow_*`)
- `16`: Background Box (`background_*` / `text_bg_*`)

Therefore:
- **`check_flag = 15` (`1 + 2 + 4 + 8`) — Boxless Subtitle (No Grey/Black Background Box)**:
  - Enables Fill + Stroke + Shadow while **completely disabling** the background box.
  - Also set `background_alpha = 0.0`, `background_style = 0`, `text_bg_alpha = 0.0`, `text_bg_round_radius_ratio = 0.0`.
- **`check_flag = 23` (`1 + 2 + 4 + 16`) — Boxed Subtitle (Rounded Dark Background Pill)**:
  - Enables Fill + Stroke + Background Box.
  - **Critical Box Offset Invariant**: Always set `background_horizontal_offset = 0.0` and `background_vertical_offset = 0.0` (`text_bg_horizontal_offset = 0.0`, `text_bg_vertical_offset = 0.0`). In CapCut's normalized coordinate space (`[-1, 1]`), setting `0.5` shifts the background pill halfway off the text instead of centering it!

### 2.3 Transform & Scale Synchronization
- Every subtitle segment must have:
  - `segment["clip"]["transform"] = {"x": 0.0, "y": y_pos}`
  - `segment["clip"]["scale"] = {"x": 1.0, "y": 1.0}`
  - `segment["uniform_scale"] = {"on": True, "value": 1.0}`
  - `mat["fixed_width"] = -1.0`, `mat["fixed_height"] = -1.0`

## 3. macOS Font Engine & App Sandbox Rule (`.ttc -> .ttf`)

1. **Why `.ttc` Paths Fail in CapCut**:
   - System font collections like `/System/Library/Fonts/Menlo.ttc`, `Seravek.ttc`, `Baskerville.ttc`, `Optima.ttc`, `Avenir Next.ttc`, and `Didot.ttc` contain multiple faces inside a single `.ttc` container.
   - CapCut's HarfBuzz/FreeType text renderer cannot select a non-zero face index from a raw `.ttc` file path reliably and falls back to the system default font.
2. **Why `~/Library/Fonts` Alone Is Not Enough**:
   - Overseas CapCut (`com.lemon.lvoverseas`) runs inside a macOS App Sandbox container whose home directory is remapped to `/Users/<user>/Library/Containers/com.lemon.lvoverseas/Data/`.
   - A font saved only to `/Users/<user>/Library/Fonts/` is outside the sandbox container unless also written into `/Users/<user>/Library/Containers/com.lemon.lvoverseas/Data/Library/Fonts/`.
3. **Mandatory Extraction Procedure**:
   - Use `fontTools.ttLib.TTCollection` to extract the target face by PostScript name (`nameID = 6`) as a standalone `.ttf` file into **both**:
     - `/Users/<user>/Library/Fonts/<PostScriptName>.ttf`
     - `/Users/<user>/Library/Containers/com.lemon.lvoverseas/Data/Library/Fonts/<PostScriptName>.ttf`
   - Point `font_path`, `font_url`, and `styles[0].font.path` to the sandbox `.ttf` path (or `/Users/<user>/Library/Fonts/<PostScriptName>.ttf` when mirrored in both directories).

## 4. Production Subtitle Style Presets

### 4.1 `white-cinematic-boxless` (Default When User Provides No Subtitle Reference Image)
Used in `1029` (*The Sunday Chair*) and `1014`. Clean, warm, cinematic boxless monospaced subtitle:
- **Font**: `Menlo-Regular` (`Menlo-Regular.ttf`, extracted from `/System/Library/Fonts/Menlo.ttc` index `0`)
- **Size**: `4.2` (`styles[0].size = 4.2`, `font_size = 4.2`)
- **Fill Color**: Warm Paper White `#FFFDF8` (`[1.0, 0.992157, 0.972549]`)
- **Position**: Bottom center `x = 0.0`, `y = -0.74`
- **Box**: Disabled (`check_flag = 15`, `background_alpha = 0.0`, `background_style = 0`)
- **Stroke**: `#080605` (`[0.031373, 0.023529, 0.019608]`), `width = 0.016`, `alpha = 0.95`
- **Shadow**: `#000000`, `alpha = 0.88`, `diffuse / blur = 0.28`, `distance = 4.0`, `angle = -70.0`
- **Line Wrapping**: Max `42` chars per line, up to `2` balanced lines (`line_spacing = 0.02`, `letter_spacing = 0.01`)

### 4.2 `yellow-cinema-boxless` (Reference-Matched Classic European / Crime / Broadcast Yellow)
Used in `1030` (*One More Bowl*, matching user reference screenshot):
- **Font**: `Seravek-Medium` (`Seravek-Medium.ttf`, extracted from `/System/Library/Fonts/Supplemental/Seravek.ttc` index `4`)
- **Size**: `4.4` (`styles[0].size = 4.4`, `font_size = 4.4`)
- **Fill Color**: Warm Muted Gold-Yellow `#E5CE6E` (`[0.898039, 0.807843, 0.431373]`)
- **Position**: Bottom center `x = 0.0`, `y = -0.78`
- **Box**: Disabled (`check_flag = 15`, `background_alpha = 0.0`, `background_style = 0`)
- **Stroke**: `#080808` (`[0.031373, 0.031373, 0.031373]`), `width = 0.012`, `alpha = 0.92`
- **Shadow**: `#000000`, `alpha = 0.85`, `diffuse / blur = 0.22`, `distance = 3.5`, `angle = -70.0`
- **Line Wrapping**: Max `44` chars per line, up to `2` balanced lines (`line_spacing = 0.02`, `letter_spacing = 0.0`)

### 4.3 `boxed-monospaced` (Dark Translucent Rounded Box)
Used in `1026` when the user explicitly requests a dark pill background behind subtitles:
- **Font**: `Menlo-Regular` (`Menlo-Regular.ttf`)
- **Size**: `4.1`
- **Fill Color**: `#FFFDF8` (`[1.0, 0.992157, 0.972549]`)
- **Position**: `x = 0.0`, `y = -0.74`
- **Box**: Enabled (`check_flag = 23`, `background_style = 1`, `background_color = "#14110E"`, `background_alpha = 0.62`, `background_round_radius = 0.22`, `background_height = 0.14`, `background_width = 0.14`, `background_horizontal_offset = 0.0`, `background_vertical_offset = 0.0`)
- **Stroke**: `#080605`, `width = 0.008`, `alpha = 0.85`
